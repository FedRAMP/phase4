# A-130 Class G Pilot Schedule

The A-130 Class G Pilot is operating under an informal schedule to maximize participation and convenience for agencies that wish to participate. This pilot will run throughout FedRAMP 20x Phase 4, which began in FY27 Q1 and will end in FY27 Q3.

FedRAMP recommends that agencies plan on developing their Class G Certification Package between January 2027 and April 2027, to submit for a Class G Certification by May 2027. FedRAMP will finalize Class G Rules and open a formal non-pilot pipeline in FY27 Q4.

| Start Date | End Date  (2027)| Activities |
| -- | -- | -- |
| November 16, 2026 | April 26, 2027 | Agency providers develop Class G Certification packages for agency-provided offerings within the scope of this pilot. |
| January 1, 2027  | June 10, 2027 | Agency providers may submit their Class G Certification package at any time during this period to apply for a Class G FedRAMP Certification. |
| March 15 | March 26 | Participants submit their draft pilot package for initial review. |
| May 17 | May 28 | Participants submit their pilot package for final review. |
| June | June | Participants demonstrate their pilot package government-wide at FedRAMP Day. |
| July | August | CR27 rules are finalized and published. |
