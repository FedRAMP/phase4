# Ready Conversion

Ready Conversion gives providers that have completed FedRAMP Ready work a path to apply for Rev5 Program Certification.

## Eligibility

Your offering must have met **at least one** of these conditions between January 2025 and December 2026.

- Your offering completed a FedRAMP Ready assessment with a Readiness Assessment Report (RAR).
- Your offering achieved FedRAMP Ready status on the FedRAMP Marketplace.

!!! warning "You **must** be able to demonstrate ageny use cases!"

    Please review [MKT-IIP-AGU (Agency Use Cases)](https://www.fedramp.gov/2026/reference/marketplace-listing/#agency-use-cases) and prepare proof that your cloud service is eligible for a Program Certification. This requirement was not in place for legacy FedRAMP Ready because it is a result of recent changes to the statutory and regulatory environment.

    If you have any doubts about being able to supply the necessary proof that your cloud service offering has direct or indirect agency use applications, please [contact FedRAMP using this form](ADDME) before investing any further in a FedRAMP Certification.

## Application Timelines

Ready Conversion does not require pre-application but [contacting FedRAMP using this form](ADDME) to confirm eligibility is recommended. Eligible cloud services can apply for a FedRAMP Rev5 Program Certification once they have a full CR26-compliant Certification Package and have met all requirements for FedRAMP Certification.

!!! tip "You can confirm your eligibility with FedRAMP in advance!"

    To avoid any possible confusion, FedRAMP recommends [contacting us using this form](ADDME) before investing any further in a FedRAMP Certification to ensure that your cloud service offering qualifies for this initiative.

| Date | Action |
| -- | -- |
| March 26, 2027 | Final day for submitting a full CR26-compliant application for FedRAMP Certification |

!!! info "Already accepted?"

    If you have met with FedRAMP and been accepted into Ready Conversion, you have completed the first step. Your Certification application is still due March 26.

## Application Process

Follow the Consolidated Rules for 2026 to apply for a FedRAMP Rev5 Program Certification with a complete CR26-compliant Certification Package prior to March 26, 2027.
