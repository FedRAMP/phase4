# Li-SaaS Conversion

Cloud service offerings with a historical FedRAMP Rev5 Li-SaaS Certification have been combined into the FedRAMP Class B Certification category pending a transition to the full FedRAMP Class B rules. FedRAMP will separately announce timelines for the retirement of Li-SaaS and a mandatory transition to full FedRAMP Class B Certification.

FedRAMP expects cloud service offerings to transition from a historical Li-Saas Certification to a full FedRAMP 20x Class B or C Certification. FedRAMP 20x is designed for many of the same use cases, the burden for maintaining a FedRAMP 20x Class B is much lower than a FedRAMP Rev5 Class B, and the FedRAMP 20x Certification type aligns better with typical private sector security programs.

In rare cases, cloud services have invested heavily into a government-specific Rev5-based product platform and may not be well positioned to transition to FedRAMP 20x. This Rev5 Program Closeout Initiative is intended to help such Li-SaaS providers that have already invested in preparing for a full FedRAMP Class B or C Certification.

!!! danger "The FedRAMP Rev5 Class B Li-SaaS designation will be retired!"

    FedRAMP is planning for end of life for all current FedRAMP Rev5 Class B Li-SaaS Certifications by the end of 2027. Cloud service providers that wish to convert to a FedRAMP Rev5 Class B or C Program Certification have a limited window, after which they will be required to migrate to a FedRAMP 20x Certification.

## Eligibility

Your offering must have held an active FedRAMP Li-SaaS (Class B) Certification between **January 2026 and December 2026**.

Conversion is available for **Rev5 Class B or Class C** only.

## Application Timelines

| Date | Action |
| -- | -- |
| April 26, 2027 | Final day for submitting a full CR26-compliant application for FedRAMP Certification |

## Application Process

Follow the Consolidated Rules for 2026 to apply for a FedRAMP Rev5 Program Certification (Class B or Class C only) with a complete CR26-compliant Certification Package prior to April 26, 2027.
