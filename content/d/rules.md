# 20x Class D Pilot Rules

!!! info "20x Class D requirements are currently open for public comment!"

    [RFC-0036 FedRAMP 20x Class D Cloud-Hosted Pilot Requirements](https://www.fedramp.gov/rfcs/0036/) contains the proposed
    requirements for the 20x Class D pilot. These requirements will change after public comment, but the RFC shows the
    anticipated scale and scope of increased assurance expectations for 20x Class D.
